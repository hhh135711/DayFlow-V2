# DayFlow 每日计划 v2 — 纯离线 Android 应用

## 本次升级
- 简洁白色卡片式中文界面，蓝色主色调，任务时间轴与完成进度。
- 计划支持跨午夜：例如 23:00 开始 180 分钟的任务，显示为 `23:00 — 次日 02:00`。
- 计划永远归属创建时选择的日期；次日凌晨的任务仍在原日期历史中。
- 使用 `start_offset` 保存从计划日期零点起的绝对分钟数，不会因午夜而回绕。
- 数据库由 v1 自动升级到 v2，保留旧任务和模板。旧数据的时间仍可正常查看。
- 仍支持模板、备注、完成打卡、历史回顾，完全离线。

## GitHub Actions 云端打包
把 `DayPlannerOffline` 文件夹**内部的全部文件**放在 GitHub 仓库根目录（包括隐藏的 `.github` 目录）。提交到 main 分支后，在 Actions 中查看 `Build Android APK`，成功后从 Artifacts 下载 `DayPlannerOffline-APK`，解压获得 `app-debug.apk`。

## 注意
- ZIP 是**完整源码工程**，不是 APK；云端编译未在此环境实际验证。
- 此版保持原包名 `com.example.dayplanner`，但不同签名的 APK 可能无法覆盖安装旧版；卸载旧版会清空本地数据，操作前请注意。
- 编辑单条计划的开始时间不会自动移动其他任务；按模板重新生成才会整体顺延，并覆盖所选日期已有计划。
- 清除应用数据或卸载应用会删除本地历史记录；目前没有备份/恢复功能。
